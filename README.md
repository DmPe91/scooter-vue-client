# Scooter43 Client (Vue)

Фронтенд интернет-магазина электротранспорта SCOOTER43.

## Стек

- Vue 3 (Composition API)
- Vite
- Pinia
- Vue Router
- Axios
- Bootstrap

## Возможности

- Каталог товаров
- Фильтрация по типу и состоянию
- Страница товара
- Корзина (добавление, удаление, просмотр)
- Уведомления (тосты)
- Прелоадер

## Запуск

```bash
git clone git@github.com:DmPe91/scooter-vue-client.git
cd scooter-vue-client
npm install
npm run dev
```
